# Créditos e materiais de terceiros

Este projeto foi desenvolvido como exercício de portfólio a partir da aula de
Flappy Bird do [Curso de Extensão — Lua + LÖVE2D](https://github.com/ConwayUSP/CursoExtensaoGameDev),
ministrado na USP. O repositório do curso informa licença MIT para o código e
CC BY-SA 4.0 para os materiais escritos.

## Bibliotecas

- `lib/push.lua`: **push v0.4**, de Ulysse Ramage, sob licença MIT. O aviso de
  copyright e a licença foram preservados no próprio arquivo.
- `lib/class.lua`: sistema de classes distribuído com o material do curso.

## Recursos audiovisuais

Sprites, fontes e efeitos sonoros vieram do pacote didático da aula e são
mantidos aqui exclusivamente para demonstrar o exercício. Para reutilização
comercial, confirme a licença individual de cada recurso com os autores do
material original.

O arquivo musical temático presente na aula não foi incluído neste projeto.
